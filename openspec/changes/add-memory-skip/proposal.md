# 提案：记忆模式新增「跳过」操作（add-memory-skip）

## Why（为什么改）

用户在手机上刷记忆模式时，偶尔会发现当前这道题本身有问题（题干/答案有误）。但 App 端改题不方便，他希望**先跳过这道题**，等回到电脑上再改。现有记忆卡只有四档评分按钮和撤销按钮，没有任何「不评分、直接过」的出口 —— 想跳过只能被迫给一个评分，而这会污染 FSRS 排期与统计。

项目既有的优化清单里，这一项已被标记为待补（"记忆模式无 skip/bury，建议加跳过"）。

## What（改什么）

- 在记忆卡上新增一个「跳过」按钮（`#memSkip`），答案未翻面时也可点。
- 新增键盘快捷键 `S` 触发跳过（与现有 Enter/空格翻面、数字 1-4 评分互不冲突）。
- 跳过的语义：**游标 `memory.index` 前进 1，卡片翻面态复位**，队列数组原样不动，不写任何进度。

## What NOT（明确不改什么 / 范围外）

- **不重排队列**：跳过不把题挪到队尾（与趁热打铁「留在榜上排到队尾」的规则刻意不同）。
- **不暂埋到明天**：不新增持久化的跳过标记，不改 `PROGRESS`、不进撤销栈 `_history`、不喂趁热榜。跳过的那道题下次进入记忆模式（队列重建后）仍会按到期正常出现。
- **不动 FSRS 调度**：跳过不调用 `applySm2Grade`，间隔/稳定性/等级一律不变。
- **不改打包链路**：`openspec/` 目录是纯文档，`sync-www.js` 的 `FILES_APP` 白名单不含它，不会被同步进 `www/` 或 APK。

## Impact（影响面）

- 受影响代码：`index.html` 记忆卡渲染（`renderMemory` 骨架 / `bindMemoryCard` / `paintMemoryCard`）、全局键盘 `keydown` 的记忆分支、相关 CSS。
- 受影响测试：`scripts/smoke-test.js` 增加「跳过零副作用」断言组；`scripts/render-smoke.js` 增加骨架含 `#memSkip` 的断言。
- 版本号：改完 `index.html` 需同步递增 `SW_VERSION` 与 `sw.js` 的 `CACHE`。
- 风险：低。跳过只是纯游标推进，回退只需删掉按钮与处理分支。
