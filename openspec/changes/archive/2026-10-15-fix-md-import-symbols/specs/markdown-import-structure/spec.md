# Spec Delta

## Purpose

规定从 Markdown 导入题库时，各级标题如何映射为「文档 / 题目」：把确实承载答案正文的标题识别为题目，而把仅作分组、其下没有正文的标题（分类名等）排除在题目之外，避免导入产生空白题目卡片。

## ADDED Requirements

### Requirement: 无正文的标题不生成题目

系统从 Markdown 解析题目时，**必须**仅把「到下一个同级/更低级标题之间存在非空正文」的标题作为题目；对标题到下一个标题之间正文为空（仅空白/换行）的标题，**必须**跳过、不为其生成题目。分类名等仅用于分组、其下直接跟另一个标题的行，即属此类。

#### Scenario: 分类标题后紧跟另一标题则不成题
- **WHEN** 文档为 `# java` 后（仅空行）紧跟 `# web`，`# web` 后紧跟 `## 你说一下前后端实现上传文件的步骤`
- **THEN** `java`、`web` 两个标题不生成题目；`你说一下前后端实现上传文件的步骤` 作为题目，其到下一个标题之间的正文作为答案

#### Scenario: 有正文的标题照常成题
- **WHEN** 某标题与其下一个标题之间存在实际正文内容
- **THEN** 该标题生成一道题目，正文作为其答案

#### Scenario: 全部标题都无正文时给出明确失败
- **WHEN** 一篇 Markdown 里每个标题下都没有正文
- **THEN** 系统不产生任何空题目，并按既有导入逻辑提示「未能从 Markdown 解析出题目」
