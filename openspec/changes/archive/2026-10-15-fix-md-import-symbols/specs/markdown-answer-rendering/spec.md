# Spec Delta

## Purpose

规定题库题目（标题与答案）在「Markdown 导入」与「刷题/浏览展示」时所遵循的渲染行为：反斜杠转义的还原范围、列表的呈现方式，以及零依赖 / HTML 转义的安全底线，避免用户看到本应被 Markdown 消化掉的裸符号。

## ADDED Requirements

### Requirement: 代码块之外还原反斜杠转义

系统展示导入题目的标题与答案时，**必须**把位于代码块与行内代码之外的 Markdown 反斜杠转义还原为其所转义的字面字符（`\<` → `<`、`\>` → `>`、`\-` → `-`、`\_` → `_`、`\*` → `*`、`\#` → `#` 等可转义标点），使这些字符不再带多余的反斜杠显示。代码围栏与行内代码内部出现的反斜杠**必须**逐字保留，不做任何还原。

#### Scenario: 代码块外的转义符被还原
- **WHEN** 答案在代码块之外含 `\<form\>`、`form\-data`
- **THEN** 刷题/浏览页显示 `<form>`、`form-data`，不再出现多余的反斜杠

#### Scenario: 代码块内的反斜杠原样保留
- **WHEN** 代码围栏内部含 `a \* b` 或正则 `\d+`
- **THEN** 显示 `a \* b`、`\d+`，其中的反斜杠不被删除

#### Scenario: 无转义内容行为不变
- **WHEN** 题目文本里没有任何反斜杠
- **THEN** 渲染结果与引入本要求之前保持一致

### Requirement: 答案中的列表渲染

系统展示导入答案时，**必须**把代码块之外、以无序标记（`-`、`*`、`+`）或有序序号（如 `1.`）开头的行渲染为真正的项目符号 / 编号列表项，而不是把标记当作裸文本显示。**相邻的列表项即使被空行分隔（松列表）也必须归入同一个列表**；有序列表**必须**按首项原序号设置起始编号（`start`），不得因拆段而从 1 重数。位于代码围栏或行内代码内的同类行**必须**保持为代码文本，不转成列表。

#### Scenario: 无序列表显示为项目符号
- **WHEN** 答案正文行以 `- 前端部分` 开头且不在代码内
- **THEN** 渲染为圆点项目符号列表项，行首不残留裸的 `-`

#### Scenario: 有序列表显示为编号
- **WHEN** 答案正文行以 `1. 创建表单` 开头且不在代码内
- **THEN** 渲染为带编号的列表项

#### Scenario: 代码块内的标记不误判为列表
- **WHEN** `- ` 或 `1. ` 出现在代码围栏内部
- **THEN** 原样保留为代码文本，不转换成列表

#### Scenario: 空行分隔的有序项归入同一列表且保留序号
- **WHEN** 答案中 `1. 甲` 与 `2. 乙` 之间隔了一个空行（松列表）
- **THEN** 渲染为一个包含两个 `<li>` 的 `<ol>`，且显示为 1. / 2.（不拆成两个各自从 1 重数的列表）

### Requirement: 搜索结果摘要同样清理符号

系统展示搜索结果卡片中的答案摘要时，**必须**像答案正文那样去掉代码块之外的反斜杠转义符并将 Markdown 标记（`**`、`` ` ``等）降为纯文本，使搜索摘要不出现裸的 `\<` / `\>` / `\-` 等多余符号。

#### Scenario: 搜索摘要不露出反斜杠
- **WHEN** 某题答案含代码块外的 `\<form\>`，该题出现在搜索结果中
- **THEN** 摘要显示 `<form>`，不显示多余的反斜杠

#### Scenario: 摘要为纯文本（不注入块级 HTML）
- **WHEN** 答案含列表/围栏等标记，被截成搜索摘要
- **THEN** 摘要以纯文本形式呈现（无 `<ul>`/`<pre>` 等块级标签），行内标记不残留

### Requirement: 零依赖与 HTML 转义安全底线

系统对题目内容的 Markdown 处理**必须**在无运行时第三方库的前提下实现，并**必须**继续对 HTML 敏感字符（`&`、`<`、`>`、`"`）做转义，使导入内容无法注入可执行标记；本要求不改变既有转义与 CSP 安全边界。

#### Scenario: 未被转义的尖括号仍按字面文本显示
- **WHEN** 答案含未以反斜杠包裹的尖括号（如 `List<String>`、`<https://x/a>`）
- **THEN** 显示为字面文本，不被解析或执行为 HTML 标签

#### Scenario: 不新增运行时渲染依赖
- **WHEN** 审阅本次变更
- **THEN** 未引入任何运行时 Markdown 库或构建期转译，应用的单文件 / 离线 / 零运行时依赖特性保持不变
