# Spec Delta

## Purpose

约束记忆模式（FSRS）如何为每道题排下一次复习：四档评分映射为间隔，以及全局固定参数（目标保留率、掌握最小间隔、忘了的回落间隔）与「任何题最长间隔」这一陈旧度上限。用于保证面试随时可能发生时，题目不会长期不出现。

## ADDED Requirements

### Requirement: 复习间隔上限（最大陈旧度）

系统 SHALL 把任意一道题的下次复习间隔封顶在 7 天以内：无论该题的记忆稳定度多高、评的是哪一档（「忘了」除外，其固定为半天），排定的下次间隔都不得超过 7 天。

#### Scenario: 熟练题排期封顶 7 天

- **WHEN** 一道高稳定度题被评「差不多(GOOD)」或「倒背如流(EASY)」
- **THEN** 其下次复习间隔 `≤ 7` 天（`fsrsIntervalDays` 结果被 `FSRS_MAX_INTERVAL=7` 截断）

#### Scenario: 「忘了」回落到半天

- **WHEN** 一道题被评「完全忘了(AGAIN)」
- **THEN** 下次间隔为 0.5 天（`FSRS_AGAIN_INTERVAL`），同样满足 ≤7 天上限

#### Scenario: 存量按新上限重排

- **WHEN** 设备升级到本版本、本地存在按旧上限（14 天）排到 >7 天后的题
- **THEN** 启动时一次性重排（复用 `rescheduleAllProgress`），使这些题的下次复习回到 ≤7 天，且重排只改排期、不改动稳定度/难度等记忆状态
