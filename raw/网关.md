# 你们项目一般用网关来做什么？

统一鉴权：所有请求先进网关，在Gateway里解析JWT token、校验用户身份。校验通过才路由到下游服务，不通过直接在网关层返回401，不用每个微服务自己写一遍鉴权代码。

路由转发：配合Nacos注册中心做服务发现，前端请求打过来，网关根据路径前缀自动路由到对应的微服务。

统一Cors：在网关一层配跨域，下游微服务全不管跨域。

请求日志+traceId：在网关的全局过滤器里生成traceId放进请求头，后面服务打印日志时自动带上，出问题靠一个traceId串起整个调用链。

我们就用的 Spring Cloud Gateway + Nacos，前端请求全过网关，鉴权、跨域、路由、日志在这层统一处理，下游服务只关心自己那块的业务逻辑。
