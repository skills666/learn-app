# 并发

# 什么是aqs？aqs有哪些常用的实现？

AQS（AbstractQueuedSynchronizer）是java并发包JUC的核心抽象类，用来构建锁和同步器的框架；它维护了一个int类型的state表示同步状态；还有一个CLH双向队列存等待线程。

常用实现：

ReentrantLock：独占可重入互斥锁

Semaphore：共享信号量控制并发数

CountDownLatch：倒计数等待子任务完成

ReentrantReadWriteLock：读写锁

CyclicBarrier：虽然不直接继承AQS，但内部用ReentrantLock也依赖AQS

# volatile关键字的作用是什么？

保证可见性：一个线程修改了volatile变量，其他线程马上就能看到最新值；volatile写操作会插入内存屏障，会强制刷新到主内存，读操作强制从主内存加载。

禁止指令重排序：JVM 和 CPU 会为了提升性能，打乱指令执行的顺序。单线程下结果不变，但多线程下可能出问题。volatile 禁止这种重排。

不保证原子性：volatile不能替代synchronized，像count++这种复合操作不行，要原子性用AtomicInteger或加锁。

# 线程和进程的区别？说一下线程有哪些状态？说一下java线程有哪些状态？怎么杀死一个线程？什么是守护和非守护线程？

线程是 CPU 调度最小单位，同一个进程里的线程共享内存，切换快，但一个线程崩了可能带崩整个进程。

进程是操作系统分配资源的最小单位，独立的内存空间，挂了不影响其他进程。创建销毁开销大。

线程的状态有五种：

新建、就绪、运行、阻塞、终止

java线程的状态有六种：

新建NEW、可运行RUNNABLE、阻塞BLOCKED、等待WAITING、等待超时TIMED_WAITING、终止TERMINATED；

java的可运行合并了操作系统的就绪和运行两种状态。调用start()后线程是可运行状态，但有没有在CPU上跑要看操作系统调度。

杀线程有两种方案，一是volatile标志位，线程自己轮询检查，true就退出，但线程在阻塞期间没法检查；二是interrupt()，能强制唤醒sleep/wait的线程并抛出InterruptedException，比标志位更全面。

守护线程就是JVM退出的时候不会等的线程，必须在start之前手动设置；非守护线程就是用户线程，JVM退出时会等所有用户线程结束。

常见的守护线程：GC线程、JVM的Finalizer线程

# 实现多线程有哪些方式？

有四种方式：

继承Thread类；继承后不能再继承其他类

实现Runnable接口；可以继承其他类，但是没有返回值，不能抛受检异常

实现Callable接口；有返回值也能抛异常，但启动要包一层FutureTask

线程池；管理方便、性能高，缺点就是配置参数多，调优复杂

# sleep和wait的区别

sleep是Thread类的静态方法，睡眠不会释放锁，时间到会自动醒，什么地方都可以用；

wait是Object类的实例方法，等待时会释放锁进入等待队列，必须在synchronized块里，否则抛异常。

# 什么是线程安全？怎么解决线程安全问题？

线程安全就是多个线程同时访问同一个对象或共享变量时，不会导致数据的不一致或程序的异常行为。

解决线程安全问题有三种思路：

第一种：多线程同时写就加锁，保证同时间只有一个线程操作。

补充：synchronized自动加解锁，简单省心；Lock手动控制，比synchronized多三个能力，可中断获取锁、尝试非阻塞获取锁、公平锁；Atomic原子类，底层是CAS无锁自旋，不加锁但保证原子性。

第二种：一个线程写其他线程读，用volatile保证可见性就行。修改后其他线程可以马上看到最新值。

第三种：每个线程操作自己的数据，避免竞争。可以用ThreadLocal，每个线程独立持有变量副本，互不干扰；也可以用局部变量，每个线程调用方法时都是独立的栈帧；还有并发容器，ConcurrentHashMap、CopyOnWriteArrayList，内部做好了线程安全，不用自己加锁。
