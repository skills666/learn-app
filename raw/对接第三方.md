# 你有对接过一些第三方吗？说一下小程序登录的流程

对接过，像微信小程序登录。

用户打开小程序，前端会调wx.login()，微信返回一个临时的code，有效期大概五分钟。

前端把这个code传给我们后端。

后端拿到code，加上小程序的appId和appSecret，调微信的code2Session接口。

微信校验通过后返回openid和session_key。

后端拿到openid后，查数据库，新用户会自动注册一个账号，老用户直接返回。然后生成我们自己的JWTtoken，把openid和userId放进去，返回给前端。

之后前端每次请求都会带上这个token，后端网关层解析校验，确认身份。

# 你们设备是怎么上报数据的？你们是怎么对接物联网iot平台的？

康寿云项目里对接过，用的是阿里云 IoT 平台。设备端通过 MQTT 协议把数据上报到阿里云 IoT，后端订阅对应的主题拉数据，解析后当天数据存 Redis 做实时展示，历史数据落库。

异常数据比如心率超了或者报警器被触发，走 RabbitMQ 异步通知护工和家属，加定时任务兜底保证不丢。
