# js中=、==、===的区别

=是把右边的值赋给左边。

==是相等运算符，比较两边的值是否相等；如果类型不一样会先做隐式转换。引用类型比的是内存地址，不是内容。

===是严格相等运算符，先比较类型，类型不一样直接返回false，类型一样再比值。引用类型也是比地址。

# vue的生命周期

VUE实例从创建到销毁的整个过程，主要分四个阶段八个钩子函数。

创建的时候，beforeCreate啥也干不了，data还没初始化。created的时候数据能用了，一般在这发请求。

挂载的时候，beforeMount模板好了但没上页面。mounted的时候DOM出来了，该初始化图表插件就在这干。

更新的时候beforeUpdate和updated，触发一般不直接用，容易搞成死循环。

销毁的时候beforeDestroy最重要，清定时器、关WebSocket都在这，不然内存泄漏。

# vue的常用标签有哪些？

常用的有v-for列表循环、v-if和v-show条件显示或隐藏、v-bind数据绑定、v-on事件绑定、v-model双向数据绑定，大概就这些。

# v-if和v-show的区别

v-if 是真正的条件渲染，不满足条件时DOM不会被创建，切换时会销毁重建，切换开销大。适合条件很少改变的场景，比如登录状态切换。

v-show 不管初始条件是什么都会渲染到DOM，只是通过 display: none 控制显隐。初始渲染开销大，但切换只是改个CSS，开销极小。适合频繁切换的场景，比如Tab切换、弹窗显隐。

# 前端的token是存在哪里的？浏览器重启了token还在吗？

Token存在pinia store里，和Vue实例同生命周期，浏览器关了，Vue实例销毁，内存释放Token就没了。所以每次打开页面都会先检查store里有没有Token，没有就跳登录页面。

可以考虑把几个接口合并成一个，减少网络IO。
